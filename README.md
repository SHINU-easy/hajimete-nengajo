# はじめての年賀状｜夜間中学・日本語クラスのための年賀状ワークショップ

© 上野振宇

夜間中学に通う、来日間もない外国にルーツを持つ生徒が、日本の年賀状の文化を知り、実際に年賀状と宛名を書くための単一HTMLのウェブアプリです。入力内容はお使いのブラウザ内にだけ保存されます（外部には送信されません）。

- 公開ページ：https://shinu-easy.github.io/hajimete-nengajo/
- ファイル：`index.html`（これだけで動作します）

## 主な内容

- 知る・ことば・かたち（前文・主文・末文・後付け）・書く・あてな・クイズ・先生へ の7タブ
- やさしい日本語（ふりがな付き）に、英語・中国語（簡体字）・ベトナム語・ネパール語・ミャンマー語の訳を複数選んで併記。ブラウザの音声合成で読み上げ（使える言語は端末によります）
- 「かんたん（3つの部分）」「ふつう（4つの部分）」の2つの書き方
- はがきサイズ（100×148mm）で印刷：完成版・なぞりがき（中心線つき）・ふりがなつき・宛名面
- 干支・和暦は日付から毎年自動で切り替え。郵便の日程・料金は年ごとに `index.html` 内の `CONFIG` へ登録（未登録の年は一般的な案内を表示）

## ご注意

- ベトナム語・ネパール語・ミャンマー語の訳は、母語話者による確認の前の試訳です。
- 文字の表示にGoogleフォントを読み込みます。インターネットにつながらない場合は、端末のフォントで表示されます。
- 内容は、日本郵便の教材『手紙の書き方体験授業』（2026年度）・『楽しい年賀状を作ろう！』（令和9年版）などを参考に作成しました。教材のイラストや文章はそのまま使っていません。出典はアプリの「先生へ」タブにあります。
